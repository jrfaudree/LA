\item (20 points) Consider the following system $A\bx = \bb$:  
\begin{align*}
x + 2y - z &= 3\\
2x + 5y + 2z &= 4\\
x + 4y + 4z &= -1
\end{align*}

	\begin{enumerate}
	\item Solve the linear system by \emph{elimination} and then \emph{back-substitution} on the \emph{augmented matrix}.  Use the standard algorithm.  
	\vfill
	\item List the pivots.
	\vspace{0.5in}
	\item Using your work in part(a), determine the $LU$-factorization of the matrix $A.$
	\vspace{1in}
	\item Suppose the vector $\bb=(3,4,-1)$ was replaced with the vector $\bc=(3,3,3)$, would the system $A \bx =\bc$ have a solution? (You should answer this question without doing any additional work.)
	\vspace{1in}
	\end{enumerate}
